# Facilitator Questionnaire — Activity 6

## Anchor and Frame an Agency Retainer

1. Should the brand make the first offer, and why?
2. What evidence makes the anchor credible rather than arbitrary?
3. How should value be framed without overstating uncertain performance?
4. Which concessions should be conditional and reciprocal?

## Challenge questions

1. Which claim is a verified fact, which is a hypothesis, and which still needs evidence?
2. What would cause your target, reservation point or package to change?
3. Which stakeholder, authority limit or implementation risk could invalidate the plan?
4. How will you demonstrate an executable agreement rather than a verbal understanding?
